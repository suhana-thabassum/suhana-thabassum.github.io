# Personal Portfolio Website

## Project Overview
This project is a personal portfolio website developed using HTML5 and CSS3. It showcases my profile, technical skills, academic projects, and contact information in a clean, modern design.

## Technologies Used
- HTML5
- CSS3
- Visual Studio Code
- GitHub Pages

## Features
- Home section with personal introduction
- About Me section
- Technical skills section
- Project cards with descriptions
- Contact section with LinkedIn QR code
- Responsive design for desktop and mobile screens
- Navigation links between website sections
